# Analyzing Historical Stock and Revenue Data

Final assignment of an IBM Data Science course: extract stock prices and quarterly revenue for Tesla and GameStop, then plot them together in an interactive dashboard.

## Steps

1. Download Tesla (`TSLA`) stock history with **yfinance**
2. Scrape Tesla's quarterly revenue table with **requests** and **BeautifulSoup**
3. Download GameStop (`GME`) stock history with yfinance
4. Scrape GameStop's quarterly revenue table
5. Plot share price and revenue for both companies with **Plotly** (`make_graph`)

## Stack

Python · pandas · yfinance · requests · BeautifulSoup · Plotly

All the work is in `Final Assignment.ipynb`.
